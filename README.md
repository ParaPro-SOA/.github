# ParaPro organization profile

This repository holds the public text displayed on the [ParaPro GitHub organization page](https://github.com/ParaPro-SOA). The organization profile lives in [`profile/README.md`](profile/README.md).

The square [`profile/avatar.png`](profile/avatar.png) is a 512-pixel rendering of the ParaPro mark used by the application.

ParaPro's application source is maintained in a private repository. The profile describes the product at a high level and does not imply that the proof of concept is suitable for real client advice.
